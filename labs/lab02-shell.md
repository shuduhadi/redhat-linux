# Lab 2 - Introduction to the Shell

## Objective

Practice basic shell navigation and command structure.

## Tasks Completed

- Displayed the current directory.
- Listed files and directories.
- Practiced changing directories.
- Checked the size of a directory.
- Used tab completion to navigate directories.

## Commands Used

```bash
pwd
ls
ls -la
cd /usr/share
du -sh /home/$USER
```

## Outcome

I successfully navigated the file system and used `du` to view the size of my home directory. I also practiced using tab completion to speed up typing commands.

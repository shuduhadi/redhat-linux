# Lab 6 - Basic File Management

## Objective

Practice creating, viewing, copying, moving, renaming, and deleting files and directories.

## Tasks Completed

- Listed files using different `ls` options.
- Created directories.
- Created an empty file.
- Copied a file.
- Renamed a file.
- Deleted files and directories.

## Commands Used

```bash
mkdir practice
cd practice

touch notes.txt

ls -l
ls -lh
ls -lha

cp notes.txt backup.txt

mv backup.txt lesson6.txt

rm lesson6.txt

cd ..
rm -r practice
```

## Practice

- Compared the output of `ls -l`, `ls -lh`, and `ls -lha`.
- Created and removed directories.
- Copied and renamed files.
- Deleted files and directories after completing the exercise.

## Outcome

I successfully practiced the basic Linux file management commands. I can now create, copy, move, rename, and delete files and directories using the command line.

# Lab 5 - Linux File System Hierarchy

## Objective

Explore the Linux file system and identify the purpose of common directories.

## Tasks Completed

- Listed the directories under the root directory.
- Navigated between directories.
- Printed the current working directory.
- Explored `/home`, `/etc`, `/var`, and `/usr`.
- Viewed executable programs and system logs.

## Commands Used

```bash
ls /
pwd
cd /home
cd /etc
cd /var/log
cd /usr/bin
ls /usr/bin
ls /usr/lib64
ls /usr/share
```

## Practice

- Explored the root directory.
- Located configuration files in `/etc`.
- Viewed system logs in `/var/log`.
- Examined installed programs in `/usr/bin`.
- Learned where temporary files and mounted devices are stored.

## Outcome

I successfully explored the Linux file system hierarchy and learned the purpose of several important directories. I now know where to find user files, configuration files, logs, installed software, and temporary files.

# Lab 15 - Insights Image Builder

## Objective

Learn how to create a customized RHEL image using Insights Image Builder.

---

## Tasks Completed

- Accessed the Red Hat Hybrid Cloud Console.
- Navigated to Insights for RHEL.
- Opened Inventory.
- Navigated to Images.
- Created a RHEL 10 image blueprint.
- Selected the x86_64 architecture.
- Selected a general virtualization guest image.
- Selected the `.qcow2` image format.
- Configured system registration.
- Enabled advanced capabilities.
- Selected recommended partitioning.
- Configured package installation.
- Added a user account.
- Configured the timezone.
- Configured the hostname.
- Selected the kernel package.
- Configured firewall services and ports.
- Configured systemd services.
- Created the image blueprint.
- Generated a QCOW2 image.

---

## Practice

I practiced navigating the Red Hat Hybrid Cloud Console and creating an image blueprint.

I configured the image with the required operating system, architecture, packages, user accounts, networking, firewall settings, and system services.

I then generated a `.qcow2` image that can be used with a virtual machine.

---

## Outcome

I learned how image builders can create consistent and customized RHEL systems before deployment.

I also learned how golden images can reduce manual configuration and make deployments faster, more predictable, and consistent across different environments.

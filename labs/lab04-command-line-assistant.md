# Lab 4 - Command Line Assistant

## Objective

Learn how the RHEL Command Line Assistant works and understand the requirements for using it.

## Tasks Completed

- Learned about RHEL Lightspeed.
- Learned that the system must be registered before using the AI assistant.
- Reviewed the command used to ask the assistant questions.
- Learned the purpose of a Satellite Server.

## Commands Used

```bash
c chat "Why should I register RHEL?"
```

## Practice

- Reviewed how to ask questions using the `c chat` command.
- Learned why system registration is required.
- Explored the benefits of using a Satellite Server in an enterprise environment.

## Outcome

I learned how the RHEL Command Line Assistant integrates AI into the terminal. I also understand why system registration is required and how Satellite Server helps organizations manage software and updates more efficiently.

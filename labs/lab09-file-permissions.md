# Lab 9 - File Permissions

## Objective

Practice viewing Linux permissions and understanding how permissions affect files and directories.

## Tasks Completed

- Created a test file.
- Created a test directory.
- Viewed permissions using `ls -l`.
- Identified the owner and group of a file.
- Practiced understanding read, write, and execute permissions.
- Practiced changing file ownership.

## Commands Used

```bash
mkdir permissions-lab
cd permissions-lab
touch testfile
ls -l
ls -ld .
```

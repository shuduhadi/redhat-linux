# Lab 1 - Linux Distributions

## Objective

Understand the differences between Linux distributions and the Red Hat ecosystem.

## Activities Completed

- Learned what a Linux distribution is.
- Identified the role of the Linux kernel.
- Compared Fedora, CentOS Stream, and Red Hat Enterprise Linux (RHEL).
- Learned that RHEL, Fedora, and CentOS Stream use RPM for package management.
- Reviewed the RHEL support lifecycle.

## Comparison

| Distribution | Purpose |
|--------------|---------|
| Fedora | Community-driven distribution with the latest features and technologies. |
| CentOS Stream | Rolling preview of the next minor RHEL release. |
| RHEL | Enterprise operating system focused on stability, security, and long-term support. |

## What I Learned

Although all Linux distributions share the same Linux kernel, they differ in their software, release schedules, and target users. Fedora is ideal for trying new technologies, CentOS Stream helps test upcoming RHEL changes, and RHEL is designed for production environments where stability and support are essential.

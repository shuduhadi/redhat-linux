# Lab 3 - Using Linux Documentation

## Objective

Practice using Linux manual pages to find information about commands and configuration files.

## Tasks Completed

- Opened the manual page for a command.
- Searched for information within a man page.
- Viewed the manual page for a configuration file.
- Opened the manual page for the `man` command itself.

## Commands Used

```bash
man tar
man ls
man 5 /etc/passwd
man man
```

## Practice

- Used `/` to search for keywords inside a man page.
- Pressed `q` to exit the manual page.
- Explored how man pages describe command options and arguments.

## Outcome

I successfully used Linux man pages to learn about commands and configuration files. I now know that built-in documentation is often the quickest way to understand how a command works.

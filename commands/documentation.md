# Documentation Commands

## man

Displays the manual page for a command.

```bash
man ls
```

Example:

```bash
man tar
```

---

## Search Within a Man Page

```text
/keyword
```

Example:

```text
/option
```

Press:

- `n` → Next match
- `q` → Quit the manual page

---

## Configuration File Manuals

View documentation for configuration files.

```bash
man 5 crontab
```

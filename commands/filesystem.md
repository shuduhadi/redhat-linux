# Linux File System Commands

## List the root directory

```bash
ls /
```

Displays the directories under the root (`/`) directory.

---

## Print the current working directory

```bash
pwd
```

Shows your current location in the file system.

---

## Change directories

```bash
cd
cd /home
cd /var/log
cd /usr/bin
```

Moves to another directory.

---

## List executable programs

```bash
ls /usr/bin
```

Displays executable programs installed on the system.

---

## View shared libraries

```bash
ls /usr/lib64
```

Lists shared libraries used by applications.

---

## View shared resources

```bash
ls /usr/share
```

Lists documentation and shared application resources.

---

## View system logs

```bash
ls /var/log
```

Displays the available log files.

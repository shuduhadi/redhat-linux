# Shell Commands

## pwd
Shows the current working directory.

```bash
pwd
```

## ls
Lists files and directories.

```bash
ls
ls -l
ls -a
ls -lah
```

## cd
Changes the current directory.

```bash
cd Documents
cd ..
cd ~
```

## du
Shows disk usage.

```bash
du -sh /home/username
```

### Common Options

| Option | Meaning |
|---------|---------|
| `-h` | Human-readable sizes |
| `-s` | Summary only |

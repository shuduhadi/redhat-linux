# Vim Commands

## Open a File

```bash
vim filename.txt
```

---

## Vim Modes

| Key | Action |
|-----|--------|
| `i` | Enter Insert Mode |
| `Esc` | Return to Normal Mode |
| `:` | Enter Command Mode |

---

## Editing

Copy a line:

```text
yy
```

Paste:

```text
p
```

Paste 10 times:

```text
10p
```

Undo:

```text
u
```

Redo:

```text
Ctrl + r
```

---

## Quit Without Saving

```text
:q!
```

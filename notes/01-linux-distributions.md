## Key Concepts

- The Linux kernel is the core of every Linux distribution.
- Different distributions provide different tools, applications, system defaults, and user experiences.
- RHEL follows the Linux Filesystem Hierarchy Standard (FHS).

## Notes

### Linux Distributions
- A Linux distro is a complete operating system built around the Linux kernel.
- The Linux kernel is the central foundation of all Linux distributions.
- What makes each distro different is what is built around the kernel, such as tools, applications, system defaults, and the user experience.

### Red Hat Distributions
- **Fedora** – Brings together ideas and innovations from many open source community projects.
- **CentOS Stream** – Provides a streamlined contribution path to the next minor release of Red Hat Enterprise Linux.
- **Red Hat Enterprise Linux (RHEL)** – A production-grade operating system that provides a secure, supported, and flexible platform for critical workloads and applications.

### Package Management
- RHEL, Fedora, and CentOS Stream use the **RPM** package format.
- Package management is used to install, update, and remove software.

### Open Source
- RHEL is built on open source software.
- Red Hat contributes improvements back to the open source community.

### Distribution Differences
- Linux distributions differ in their configuration, release schedules, and included software.
- They all follow the Linux Filesystem Hierarchy Standard.

### RHEL Lifecycle
- RHEL is designed for stability and predictability.
- Major releases occur approximately every 3 years.

Support phases:
1. **Full Support (First 5 years)**
   - New features
   - Bug fixes
   - Security updates

2. **Maintenance Support (Next 5 years)**
   - Primarily security patches and maintenance updates

3. **Extended Support**
   - Selective security patches after the first two support phases have ended
